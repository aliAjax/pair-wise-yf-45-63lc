# pair-wise-yf-45 影视剧组拍摄通告与资源冲突编排

源提示词摘要：为剧组制片、导演、演员统筹和场记提供通告编排工作台，维护场次、演员档期、场地与器材占用，自动发现资源冲突，支持拖拽排序、状态流转、版本快照、撤销恢复和离线草稿。

## 技术栈

Vue3、TypeScript、Vite、Element Plus、Pinia、Vue Router、Axios、VueUse、VeeValidate、Zod、Vue I18n、Day.js。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发端口：62010

## 通告确认 / 冲突豁免 / 版本快照 规则

- **确认即快照**：只有制片、导演可以确认通告；确认时按当时的场次、演员、场地打包快照（含确认人与提交令牌）。
- **豁免只认快照**：豁免必须锚定最近一次确认快照，并记录涉及场次的要素指纹（拍摄日/起止时间、演员、场地）。要素任一变化，豁免立即作废，冲突退回待处理；恢复旧版本不会让已作废的豁免复活。
- **场记改动进待审**：非负责人调整场次要素只生成待审申请，制片/导演通过后才落盘。
- **先到先得**：两位负责人几乎同时确认同一场时，服务端按请求到达顺序做版本比较，只放行先到的一份；落败方看到是谁、何时先确认，刷新到最新基线后可重新确认。
- **失败可重试且幂等**：提交失败保留挂起包，可按原令牌重试；同一份快照重复送达只产生一版。
